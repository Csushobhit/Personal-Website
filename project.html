Hotel Recommendation Engine

Hybrid AI-Powered Hotel Recommendation System

NLP Sentiment · Haversine Geo · Cosine Similarity · Two-Layer Moderation

View on GitHub
Python Streamlit XGBoost · TF-IDF Gemini AI Haversine Detoxify ML

A hybrid AI system combining NLP sentiment analysis, geospatial proximity via the Haversine formula, cosine similarity ranking, and traveler-segment matching — backed by a two-layer content moderation pipeline and a three-tier LLM filter extractor. Covers 1,670 hotels across 1,021 cities.

Problem Statement

  • Manual search lacks personalization
  • Reviews lack recency weighting
  • No geospatial awareness in standard tools
  • Content moderation gaps in AI assistants
  • Poor traveler-type matching

Key Features

  • Haversine great-circle proximity
  • 7-dimension hybrid scoring engine
  • Two-layer content moderation
  • AI Helper: Gemini → OpenAI → Regex
  • Cosine similarity "find similar hotels"

Tech Stack

  • Python · Streamlit
  • XGBoost · TF-IDF · Scikit-learn
  • Gemini 1.5 Flash · GPT-4o-mini
  • Detoxify ML · Haversine Formula
  • 1,670 hotels · 9,879 reviews
